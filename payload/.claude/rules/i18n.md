# i18n

- **No user-facing string is hardcoded.** Every text rendered to a user goes
  through the translation function. A literal in a component is a defect.
- Keys are semantic and namespaced by feature (`cart.empty.title`), never the
  English sentence itself.
- Every key exists in every supported locale. A missing translation fails the
  build, it does not fall back silently.
- Never build a sentence by concatenating translated fragments — grammar does
  not survive it. Use interpolation and plural forms.
- Dates, numbers, and currencies go through the locale formatter, never manual
  string formatting.
